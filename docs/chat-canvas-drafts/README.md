# Chat canvas drafts (preview only)

Standalone WhatsApp-style doodle backgrounds. **Not wired into Chatwoot yet.**

Open any `.svg` in the browser. Use **Ctrl+F5** after edits.

## Anti-repeat rules used

1. **Tile 340×340** (not 170) — the pattern repeats less often on screen.
2. **~20 icon instances** per tile, same motif family but different rot/scale/opacity.
3. **Irregular positions** — not a 3×3 grid; gaps and offsets vary.
4. **Opacity range** ~0.17–0.28 so some marks are quieter and break the “stamp” look.
